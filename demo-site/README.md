# Демо-страницы ZeroStress

> **Статус (5 ноября 2026): страницы не публикуются.** Решено, что судья проверяет настоящие ссылки на основном адресе, а отдельный поддомен не нужен. Папка остаётся набором локальных проверок поведения (`check.mjs`). Раздел «Выкладка на Cloudflare Pages» ниже устарел и сохранён для истории.

Статический сайт из безопасных страниц-ловушек для демо и видео. Подробности и причины: [docs/specs/007-web-layer.md](../docs/specs/007-web-layer.md), раздел 3.8, и [docs/TOOLS.md](../docs/TOOLS.md), раздел 9.

## Что здесь
| Адрес | Что делает страница | Что должна найти проверка |
|---|---|---|
| `/` | список страниц с пояснениями | не проверяется |
| `/safe/` | обычная статья | угроз нет |
| `/login/` | форма входа вымышленной почты; пароль уходит на другой сайт | `password_form_cross_origin`, вердикт «опасно» |
| `/start` | три перенаправления на `/login/` | то же |
| `/files/` | ссылка на файл `invoice-2026.pdf.exe` (обычный текст с «исполняемым» именем) | при обычной проверке сигнала нет; файл скачивается только по действию агента и всегда после подтверждения человека |
| `/assistant-note/` | скрытый текст, обращённый к ИИ-помощникам | сработали хуки: «страница обращается к ИИ», вердикт по правилам |
| `/sandbox-test/` | один запрос к адресу метаданных облака `169.254.169.254` | в песочнице он закрыт сетью; это «containment moment» для видео |

Названия и организации вымышленные: ни одна настоящая компания не имитируется. Страницы ничего не собирают и не скачивают сами. Единственная отправка, которая возможна, это форма `/login/` на `example.org` с вымышленными данными, и только если агенту разрешит человек.

## Проверка до выкладки
`check.mjs` запускает **настоящий сборщик** (локальный Chromium) и **настоящие правила и хуки** на каждой странице, с небольшим сервером, который читает `_redirects` и `_headers` так же, как Cloudflare Pages. Chromium с песочницей не запускается от root, поэтому запускать от обычного пользователя:

```
cd collector && npm ci --ignore-scripts && npx playwright install --only-shell chromium
node demo-site/check.mjs
```
Скрипт игнорирует сигналы, которые дают только локальный сервер (адрес вместо имени, `http`). Это проверка поведения страниц, а не замена проверки через публичный адрес: последний шаг ниже.

## Почему не на нашей машине
Сеть гостя закрыта от хоста, в том числе от его публичного адреса (правило «guest to host», спека 003). Страницы, которые должна открыть песочница, обязаны стоять на внешнем публичном хостинге.

## Выкладка на Cloudflare Pages (шаги для владельца домена)
1. Cloudflare → Workers & Pages → Create → Pages → **Upload assets**, проект `zerostress-demo`, загрузить содержимое этой папки целиком, **кроме `check.mjs` и `README.md`** (они служебные, но сервер Pages их всё равно не отдаст как страницы; лучше не загружать).
2. Custom domains → добавить `demo.zerostress.space`.
3. Проверить: открыть `https://demo.zerostress.space/` и вставить адреса в ZeroStress; ожидания в таблице выше. `/start` должен дойти до формы входа через три перенаправления, а `/files/invoice-2026.pdf.exe` отдаваться как вложение.
4. Прописать список в настройку `WEB_DEMOS` службы (подписи и адреса), см. `web/server/main.ts`.
