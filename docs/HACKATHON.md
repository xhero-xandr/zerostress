# Vultr: Agent Rush Hackathon — условия

Источник: https://lablab.ai/ai-hackathons/vultr-hackathon/ плюс Rule Book, Guidelines, Getting Started Guide и Terms of Use на lablab.ai. Сведено 2026-11-03.

## Суть
«Build AI agents that do real work — safely sandboxed on Vultr.» Система должна планировать, отправлять и проверять реально выполненную работу, а не описывать её. Vultr — центральный управляющий слой, работа уходит в изолированные среды, результат проверяемый.

## Треки (выбрать один)

### Трек 1 — Blast Radius Zero (наш выбор)
Веб-агент пишет и запускает код или управляет настоящим браузером, каждое действие внутри песочницы.

- **Паттерн A:** вопрос → модель пишет код → код в контейнере → реальный результат → объяснение. Ошибки возвращаются для повторов.
- **Паттерн B:** цель → план → Playwright в контейнере → скриншоты → vision-модель проверяет → человек одобряет финальные действия.
- **Containment:**
  1. изоляция процесса (выполнение не касается хоста и среды приложения);
  2. гигиена секретов (в песочнице нет ключей и учётных данных);
  3. лимиты ресурсов (время и память на каждый запуск);
  4. жизненный цикл (среда сбрасывается или уничтожается после задачи).
- **Технологии:** Vultr VM, веб-приложение на Vultr, Vultr Serverless Inference (обязателен для LLM-вызовов агента, `https://api.vultrinference.com/v1`, OpenAI-совместимый), изолированная песочница (Docker рекомендуется; примеры: OpenSandbox, gVisor, E2B, Microsandbox). Vultr API допустим для временных инстансов. Vultr GPU недоступны.
- **Примеры направлений:** CSV Analyst, Prove-It Code Reviewer, Chart Anything, File Fixer, Self-Healing Runner, Comparison Shopper, Form Filler, Site QA Sweep, Research with Receipts, Page Watcher.

### Трек 2 — Powering the Future of Work
Корпоративная платформа с многошаговыми процессами (продажи, финансы и бухгалтерия, HR, поддержка, закупки), публичный веб-продукт. Serverless Inference необязателен, песочница не требуется.

## Что сдать
- Репозиторий GitHub с инструкциями по запуску.
- Развёртывание на Vultr VM и публичный URL.
- Видео (MP4/MOV, до 300 МБ, до 5 минут), слайды (PDF), обложка.
- Название (до 50 символов), краткое описание (до 255), полное (не меньше 100 слов), теги.
- README: используемые сервисы Vultr, архитектура бэкенда и развёртывания, сценарий использования агента. Отдельный отчёт не нужен.
- Трек 1: минимум один «containment moment» в видео.
- Подача **только через LabLab**. Подаёт админ команды и до трёх выбранных им человек. Публикация в Vultr Community необязательна и подачу не заменяет.

## Судейство
Четыре критерия, веса не объявлены:
1. Application of Technology — насколько хорошо встроены модели.
2. Presentation — ясность и эффективность презентации.
3. Business Value — практическая польза и соответствие бизнес-областям.
4. Originality — уникальность и креативность.

По Rule Book по умолчанию оценка 1–5 по каждому критерию без весов, но для этого события не подтверждено.
